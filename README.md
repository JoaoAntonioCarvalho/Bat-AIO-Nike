# Bat-AIO Nike | Legacy Automation Systems (2020-2024)

### **Project Overview**
**Bat-AIO** was a high-performance automation software (bot) specifically engineered for the Nike Brazil ecosystem. Developed over a span of 4 years, the project evolved from a lightweight CLI tool into a sophisticated desktop application designed to secure limited-edition sneakers in a highly competitive market.

The project focused on bypassing advanced anti-bot measures and outperforming global competitors to secure high-value inventory during "hype" releases.

---

## Impact & Performance
* **Duration:** 4 years of continuous development and maintenance.
* **Financial Success:** Generated over **R$ 700,000.00 (~$135,000 USD)** in revenue for a select group of 13 private clients.
* **Efficiency:** Operated with a lean monthly infrastructure cost of approximately **R$ 500.00 (~$90 USD)**.
* **Target:** Specialized in high-demand, limited-run sneakers in the Brazilian market.

---

## Tech Stack
* **Runtime:** Node.js
* **Frontend/UI:** Electron (Desktop Integration), HTML5, CSS3
* **Backend & Auth:** Firebase Auth (User Management & Licensing)
* **Networking:** Axios (Complex API Orchestration)
* **Proxy Management:** Custom VPN/Proxy rotation logic for IP masking
* **Notifications:** Discord Webhooks (Real-time checkout logs)
* **Data Management:** Advanced Cookie Manipulation & Session Persistence

---

## Key Technical Challenges & Evolution

### **1. Architecture Evolution**
The project started as a **Command Line Interface (CLI)** to maximize execution speed and minimize latency. As the user base grew, it transitioned into an **Electron-based Desktop App** to provide a better user experience without sacrificing core performance.

### **2. Anti-Bot Bypassing & Network Security**
The software operated in a constant "arms race" against Nike’s security layers. It required deep expertise in:
* **IP Orchestration:** Implementation of **VPNs and Proxy management** to handle unique IPs for multiple accounts, effectively bypassing rate limits and IP-based blacklisting.
* **Cookie Management:** Implementing complex logic to handle, generate, and inject session cookies to mimic human behavior and maintain persistence.
* **API Hardening:** Directly interacting with internal endpoints to bypass heavy frontend scripts and improve success rates during high-traffic events.

### **3. Performance & Scalability**
In the world of "sneaker botting," milliseconds matter. The bot was optimized for concurrent task execution, allowing users to run **multiple accounts and profiles simultaneously** by rotating network identities and maximizing win probability while staying within infrastructure limits.
